# SmartBank – Integrated Banking Management System (Prototype)

A single-file web prototype for the SmartBank software project management report.

## Features
- Customer view: accounts, transfers, loan applications with EMI calculator
- Staff view: customer registration, KYC verification, freeze/unfreeze, approvals, reports, audit log
- Rules: MFA sign-in (demo code `123456`), daily limit AED 20,000, maker-checker approval for transfers of AED 10,000+

## Run
Open `index.html` in a browser. No build step needed.

## Notes
Prototype only: sample data, in-memory state, no backend.
